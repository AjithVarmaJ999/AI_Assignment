# AI_Assignment

This repository contains the programming solutions for my Artificial Intelligence assignment.

## Programs

### Problem 1 - Dijkstra's Algorithm

File: `Problem1.py`

This program uses Dijkstra's algorithm to find the shortest path between two cities using the given Indian cities dataset.

The required dataset is:

`indian-cities-dataset.csv` open source dataset

The program asks the user to enter the starting city and destination city and then displays the shortest path and total distance.

### Problem 2 - A* Search

File: `Problem2.py`

This program uses the A* search algorithm for UGV path planning on a grid environment containing obstacles.

The program displays:

* Planned path
* Path length
* Number of cells explored
* Computation time
* Grid with the UGV path
